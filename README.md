
# Jumpstart

A pixel-art platformer built in **Godot** where you jump, collect stars, avoid spikes, and make it to the end!

## Play the game here!
https://ayeshasaddiqa-code.itch.io/jumpstart

## Features

* Player movement and jumping
* Collectible stars
* Spike obstacles
* Collision detection
* In-game messages for collecting stars and hitting obstacles
* End-game/win message
* Camera movement through the level
* Pixel-art visuals

## How to Play

* **Move:** Arrow Keys (right & left)
* **Jump:** Space
* **Goal:** Reach the end of the level while avoiding spikes and collecting stars!

## Built With

* **Godot Engine**
* **GDScript**
* Pixel-art assets

## What I Learned

While building Jumpstart, I learned the basics of:

* Creating a 2D platformer in Godot
* Player movement and physics
* Collision detection using `Area2D` and `CollisionShape2D`
* Working with TileMaps/TileMapLayers
* Using signals such as `body_entered`
* Creating on-screen UI messages
* Working with cameras and camera limits
* Using GDScript to create game interactions
